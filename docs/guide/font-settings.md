# 如何自定义字体

MoeKoe Music 支持从系统已安装字体中选择字体。当前有两个独立的字体设置：

- **字体设置**：用于主程序界面。
- **桌面歌词字体设置**：用于桌面歌词窗口。

这两个设置互不影响。比如您可以让主程序使用默认字体，同时让桌面歌词使用更醒目的字体。

## 设置主程序字体

1. 打开 **设置**。
2. 进入 **界面** 分类。
3. 点击 **字体设置**。
4. 在字体列表中选择一个系统字体。

选择后，主程序界面的字体会立即应用。选择 **默认字体** 可以恢复系统默认字体。

## 设置桌面歌词字体

1. 打开 **设置**。
2. 进入 **歌词** 分类。
3. 点击 **桌面歌词字体设置**。
4. 在字体列表中选择一个系统字体。

桌面歌词字体设置只影响桌面歌词窗口，不会改变主程序界面字体。选择 **默认字体** 可以恢复桌面歌词的默认字体。

## 关于旧版 Web 字体方案

旧版中提到的 Web 字体输入方案已经移除，采用更加方便快捷的方案。

现在不再需要填写字体 URL，也不再需要输入字体名称。请先在操作系统中安装需要使用的字体，然后在 MoeKoe Music 的字体列表中选择。

## 如何给系统安装字体

MoeKoe Music 会读取系统已安装的字体。如果字体列表里没有您想用的字体，请先把字体安装到操作系统中。

### Windows

1. 下载字体文件，常见格式为 `.ttf` 或 `.otf`。
2. 双击字体文件。
3. 点击 **安装** 或 **为所有用户安装**。
4. 重新打开 MoeKoe Music 的字体选择窗口。

也可以右键字体文件，选择 **安装**。

### macOS

1. 下载字体文件，常见格式为 `.ttf` 或 `.otf`。
2. 双击字体文件，打开 **字体册**。
3. 点击 **安装字体**。
4. 重新打开 MoeKoe Music 的字体选择窗口。

### Linux

1. 下载字体文件，常见格式为 `.ttf` 或 `.otf`。
2. 将字体文件复制到字体目录：
   - 仅当前用户使用：`~/.local/share/fonts`
   - 所有用户使用：`/usr/local/share/fonts`
3. 刷新字体缓存：

```bash
fc-cache -fv
```

4. 重新打开 MoeKoe Music 的字体选择窗口。

## 推荐字体

以下是一些在高分辨率屏幕上显示效果较好的字体推荐：

### 中文字体

- **Noto Sans SC** - Google 的开源字体，对中文支持良好
- **思源黑体** (Source Han Sans) - Adobe 与 Google 合作的开源字体
- **方正系列字体** - 专业的中文字体，显示效果优秀

### 英文和数字字体

- **Roboto** - Google 设计的现代无衬线字体
- **Open Sans** - 适合各种屏幕分辨率的清晰字体
- **Inter** - 专为计算机屏幕设计的字体

## 常见问题解答

### Q: 字体列表为空怎么办？

A: 字体选择依赖浏览器/客户端提供的本地字体读取能力。如果列表为空，请确认当前客户端支持本地字体权限，并且系统中已经安装了可用字体。

### Q: 我选择了字体，但某些界面元素没有变化

A: 某些特殊界面元素可能使用了固定字体。这是为了保持界面的一致性和稳定性。

### Q: 桌面歌词字体和主程序字体为什么不一样？

A: 这是正常的。主程序字体和桌面歌词字体是两个独立设置，需要分别选择。
